# Viacil - Traducción e Interpretación Accesible

![Logo](app/src/main/res/drawable/ic_logo_splash.xml)

## Características
- Cámara con Live Translation (ML Kit)
- Intérprete de frases rápidas con TTS
- Traducción y ajustes de accesibilidad
- Soporte para daltonismo y baja visión
- Modo oscuro y offline

## Tecnologías
Kotlin, CameraX, ML Kit, Material 3, DataStore
